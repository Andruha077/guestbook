# Guestbook — Книга відгуків

## Опис
Вебдодаток для додавання та перегляду відгуків користувачів.

## Технології
- Java 21
- Maven
- Jetty 11
- Jakarta Servlet API
- H2 Database
- JDBC
- Jackson
- SLF4J + Logback

## Запуск проєкту
Для запуску використовується команда:

```bash
mvn jetty:run
```

Після запуску відкрити в браузері:

http://localhost:8080/

## База даних
URL підключення:

`jdbc:h2:file:./data/guest;AUTO_SERVER=TRUE`

Файл бази даних створюється у папці `data` відносно робочої директорії програми.

## HTTP-ендпоїнти
- `GET /` — головна сторінка.
- `GET /comments` — отримання списку відгуків у форматі JSON.
- `POST /comments` — додавання нового відгуку.

## Статуси відповідей
- `204` — успішне додавання.
- `400` — помилка введення даних.
- `500` — помилка сервера або бази даних.
